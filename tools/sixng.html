SixNG

Pulls models, textures, audio, text and map data out of your own GTA VI install into glTF, PNG and WAV.

GPL-3.0Changed todayProject is 3 days oldRelease files match GitHub's hashes

Source on GitHub

What the author says it does

Author lists textures, models, map placements, collision, audio and text as working; file names are recovered from inside resources because the archive index is encrypted and not read.

Command line and desktop app. Windows, macOS, Linux. Not something we tested.

What it does not do

Some compressed textures use fitted tables, so a few blocks can be slightly off. Materials are partial.

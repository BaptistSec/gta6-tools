rage9-re

Reads script.rpf and anim.rpf, writes script data as XML or JSON and animation clips as glTF.

MIT OR Apache-2.0Changed todayProject is 3 days oldSource only

Source on GitHub

What the author says it does

Author lists script containers (PSIN) parsing for all 1,012 files in script.rpf, and animation channels decoding to .glb clips. The repository contains no game data; you supply your own files.

Command line and library. Rust and Python 3, from source.

What it does not do

Only a few named bones are mapped in the glTF export, so the full skeleton is not rebuilt. About 1% of animation steps jump by more than 20 degrees. Most field names in script data are unresolved hashes. No releases; you build it yourself.
